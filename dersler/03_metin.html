03 · Çalışma Ortamı Kurulumu — Ders Metni (ayıklanmış)

Kaynak: Hocanın YouTube'daki "LangChain: Çalışma Ortamının Kurulumu" videosu (~13 dk, kayıtlı anlatım). Transkript YouTube otomatik altyazısıdır; bu derse ait kod dosyası ve konu çizimi yoktur. Komutlar, transkriptte anlatılanlardan yeniden kurulmuştur. Not: Kütüphane sürümleri videonun çekildiği tarihe aittir (LangChain 0.1.x dönemi). Bugün kurulum yaparken PyPI'daki güncel sürümlere bakmak gerekir.

Giriş ve proje klasörü (≈00:00–00:01)

Önceki derste LangChain'e giriş yapılmış ve framework'ün bileşenleri tanıtılmıştı. Bu derste kod yazmak için çalışma ortamı kuruluyor.

İlk adım bir proje klasörü oluşturmak. Windows komut satırında mkdir komutu ve ardından klasör adı yazılır. Hoca klasör adını "langchain for GenAI" benzeri bir isim olarak veriyor (tam yazımı [belirsiz]; aşağıda langchain-for-genai olarak kullanıldı). İstenirse klasör, Windows Gezgini'nde sağ tıklayarak da oluşturulabilir. Ardından cd ile klasörün içine girilir.

mkdir langchain-for-genai
cd langchain-for-genai

Editörü açmak: VS Code (≈00:01)

Hoca editör olarak VS Code kullanıyor; isteyen PyCharm gibi başka bir editör de kullanabilir (transkriptte bir editör adı daha geçiyor, "klep" — [belirsiz]). Terminalden, bulunulan dizinde VS Code'u açmak için code komutundan sonra nokta (.) yazılır; nokta "bu dizin" anlamına gelir. Alternatif olarak VS Code içinden File → Open Folder ile de klasör açılabilir.

code .

Sanal ortam neden gerekli ve Anaconda (≈00:01–00:02)

Sanal ortam (virtual environment), proje kütüphanelerini daha kolay yönetmeyi sağlar ve farklı projelerdeki kütüphanelerin birbiriyle çakışmasını önler. Hoca her proje için ayrı bir sanal ortam kullanılmasını şiddetle tavsiye ediyor.

Sanal ortam birçok yolla kurulabilir; bu derste Anaconda kullanılıyor. Anaconda özellikle veri bilimi projeleri için geliştirilmiş bir platformdur; paket yöneticisi conda ile paket yüklenir ve yönetilir. Bilgisayarda Anaconda yoksa Anaconda'nın sitesinde "Free Download" kısmından indirme sayfasına gidilir, indirilir ve klasik "Next, Next" adımlarıyla kurulur.

Conda ile sanal ortam oluşturma ve etkinleştirme (≈00:02–00:03)

VS Code'a dönülüp yeni bir terminal açılır; terminal türü olarak Command Prompt (komut satırı) seçilir. Ortam conda create ile oluşturulur, isim -n bayrağıyla verilir. Hoca ortam adını "langchain" olarak veriyor (transkriptte "L chain / lch" olarak geçiyor; tam ad [belirsiz]). Conda, ortamın Anaconda kurulum klasöründeki envs altına kurulacağını söyler; onay için y (Yes) denip Enter'a basılır.

conda create -n langchain

Kurulum bitince conda, ortamı etkinleştirmek için conda activate, devre dışı bırakmak için conda deactivate komutlarını kullanmayı söyler. Ortam etkinleştirilir:

conda activate langchain
# çıkmak için:
conda deactivate

Ortamın etkin olduğu, satırın başında parantez içinde ortam adının görünmesinden anlaşılır. Projede çalışırken her seferinde ortamın bu şekilde etkinleştirilmesi gerekir.

Not: Transkriptte conda create komutunda Python sürümü belirtildiğine dair bir şey geçmiyor. Pratikte conda create -n langchain python=3.11 gibi bir sürüm belirtmek, ortamın içine Python ve pip'in kurulmasını garanti eder.

requirements.txt dosyası ve sürümlerin PyPI'dan bulunması (≈00:03–00:06)

Kullanılacak kütüphaneler için bir requirements.txt dosyası oluşturulur (VS Code'un sol panelinde New File → requirements.txt). Bu dosyaya kütüphaneler ve sürümleri paket==sürüm biçiminde yazılır. Kütüphanelerin son sürümleri PyPI (pypi.org) sitesinden bulunur. Hoca bu dosyayı GitHub reposuna yükleyeceğini, öğrencilerin oradan indirip kullanabileceğini söylüyor.

PyPI'da tek tek bakılan kütüphaneler ve videodaki sürümler:

  • langchain — son sürüm 0.1.6 (video çekildiğinde 17 saat önce yayınlanmış).
  • langchain-core — son sürüm 0.1.2 (18 saat önce yayınlanmış). (Sürüm transkriptte böyle geçiyor; bkz. "Ders Notları" belirsizlikler kısmı.)
  • langchain-openai — OpenAI'ın LangChain entegrasyonu; sürüm 0.0.1 olarak okunuyor.
  • python-dotenv — ortam değişkenlerini çalışma ortamına aktarmak için; sürüm 1.0.1.
langchain==0.1.6
langchain-core==0.1.2
langchain-openai==0.0.1
python-dotenv==1.0.1

Kütüphaneleri pip ile kurmak (≈00:06–00:07)

pip, Python'un paket yöneticisidir; Anaconda kurulunca pip de otomatik gelir. Dosyadaki kütüphaneler (ve bağımlılıkları) -r bayrağıyla kurulur:

pip install -r requirements.txt

Kurulum sırasında langchain ile birlikte langchain-community kütüphanesinin de otomatik yüklendiği görülüyor. Kurulan tüm kütüphaneleri görmek için bir "list" komutu kullanılıyor (transkriptte "K list"; büyük olasılıkla pip list ya da conda list — [belirsiz]):

pip list

Listede langchain 0.1.6, langchain-core 0.1.2 ve langchain-openai 0.0.1 sürümleriyle görünüyor.

Hocanın uyarısı: Kütüphaneleri VS Code içinden kurarken/kullanırken Command Palette → Python: Select Interpreter (yorumlayıcı seç) kısmından oluşturulan sanal ortamı seçmeyi unutmayın.

API anahtarı ve .env dosyası (≈00:07–00:09)

OpenAI veya Hugging Face gibi üçüncü parti servislerle çalışırken API anahtarı (API key) gerekir ve bu anahtarın çalışma ortamına alınması lazım. Bunun birkaç yolu var; en pratiklerinden biri python-dotenv kütüphanesidir. Bunun için proje dizininde bir .env dosyası oluşturulur (New File → .env) ve içine OpenAI anahtarı yazılır:

OPENAI_API_KEY=sk-...

Anahtarı almak için OpenAI platform sitesine gidilip API keys kısmına girilir. Burada daha önce oluşturulan anahtarlar görülür; yenisi oluşturulabilir. Hoca bir isim veriyor ("langchain" benzeri), Create secret key butonuna basıyor, anahtarı kopyalıyor ve Done diyor.

Hocanın vurguları: - API anahtarı yalnızca bir kez gösterilir; bir yere kaydetmek gerekir. Anahtar istenildiği zaman bu sayfadan silinebilir. - Siteye ilk kez kayıt olunduğunda OpenAI (video tarihinde) 5 dolarlık kredi veriyordu; bu kredi eğitimdeki uygulamalar için yeterli. Kredi biterse Settings → Billing kısmından ödeme kartı eklenip en az 5 dolarlık kredi alınabilir. - Hoca, eğitimden/video yayınından sonra gösterdiği anahtarı sileceğini söylüyor.

.gitignore ile anahtarı korumak (≈00:09–00:10)

Proje GitHub'a gönderilirken .env dosyasının gitmemesi için bir .gitignore dosyası oluşturulur (VS Code bu dosyayı adından otomatik tanır). İçine GitHub'a gönderilmek istenmeyen dosyalar yazılır; burada .env. Böylece API anahtarını kimse görmez, anahtar güvende kalır.

.env

Notebook oluşturma ve kernel seçimi (≈00:10–00:11)

Hoca derslerde VS Code içinde notebook kullanacak. Yeni bir dosya langchain.ipynb adıyla oluşturulur; .ipynb uzantısını gören VS Code dosyayı otomatik olarak notebook olarak açar. Sağ üst köşeden Select Kernel ile kernel olarak az önce oluşturulan langchain sanal ortamı seçilir. Böylece sanal ortam notebook içinde de ayarlanmış olur.

Ortam değişkenlerini yükleme: load_dotenv (≈00:11–00:12)

.env içindeki değişkenler dotenv modülündeki load_dotenv fonksiyonuyla yüklenir:

from dotenv import load_dotenv
load_dotenv()

Hücre ilk çalıştırıldığında VS Code, notebook için bazı paketlerin (ipykernel) kurulması gerektiğini söylüyor; Install denip kuruluyor. Ardından hücre çalışıyor ve True döndürüyor. Bu, .env içindeki OpenAI anahtarının ortam değişkeni olarak notebook'a aktarıldığı anlamına gelir. OpenAI kütüphanesi bu anahtarı (OPENAI_API_KEY adıyla) otomatik tanır.

İsterseniz anahtarın yüklendiğini os modülüyle kontrol edebilirsiniz:

import os
os.getenv("OPENAI_API_KEY")

Hücre çalışınca anahtar ekrana yazılıyor. Hoca bunu yalnızca gösterim amaçlı yaptığını, API anahtarının kesinlikle kimseyle paylaşılmaması gerektiğini vurguluyor.

Alternatif: anahtarı elle ayarlamak (≈00:12–00:13)

Anahtar elle yüklenmek istenirse os.environ kullanılabilir:

import os
os.environ["OPENAI_API_KEY"] = "sk-..."

Kontrol için yine os.getenv("OPENAI_API_KEY") kullanılabilir. Hoca çalışmalarında genellikle birinci yöntemi (python-dotenv ile .env) kullanacağını ve öğrencilere de bunu tavsiye ettiğini söylüyor.

Kapanış (≈00:13)

Bu derste çalışma ortamı ayarlandı, kütüphaneler kuruldu ve OpenAI API anahtarı ortam değişkeni olarak yüklendi. LangChain ile çalışmak için her şey hazır; bir sonraki derste LangChain'in "mutfağına" girilip kod yazılmaya başlanacak.
