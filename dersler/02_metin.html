Python neden bu kadar popüler? (≈00:00–00:05)

Son yıllarda sürücüsüz arabalar, insan gibi çalışan robotlar, film/müzik öneren uygulamalar gerçek oldu; bu gelişmeler yapay zekâ alanının ilerlemesiyle geldi ve yapay zekâ için en çok kullanılan dil Python'dur. Hoca Google Trends grafiğini gösteriyor: Türkiye'de Python son 5 yılda giderek yükselmiş, C#'ı geçip Java ile yarışır hâle gelmiş; dünya genelinde ise hem C#'ı hem Java'yı geçmiş.

Hocanın vurgusu: Teknoloji hemen her mesleğin içine girdi; hangi işi yaparsanız yapın programlama bilgisi sizi bir adım öne taşır ve işinizi kolaylaştırır. Bilgi ve geliştirme araçları artık açık kaynak; kendi kendinize çalışarak uygulama geliştirebilirsiniz. Başlangıç için en uygun dil, öğrenmesi kolay olan Python'dur; bugün birçok üniversitede ilk dil olarak okutuluyor.

Python'un özellikleri: - Nesne yönelimli, yorumlamalı (interpreted), modüler, etkileşimli ve yüksek seviyeli bir dildir. - Açık kaynak ve ücretsizdir; güçlü, esnek ve sözdizimi (syntax) sade olduğu için hızlı öğrenilir. - İlk kez 1990 yılında Guido van Rossum tarafından Amsterdam'da geliştirilmeye başlandı. Adı yılandan değil, Guido'nun çok sevdiği altı kişilik İngiliz komedi grubu Monty Python'dan gelir. - Not: Resmî kaynaklarda geliştirmenin 1989 sonunda başladığı, ilk sürümün 1991'de yayımlandığı yazar; hoca "1990" dedi. - Yorumlamalı: C'den farklı olarak kod derlenmeden çalıştırılır. - Nesne tabanlı: Sınıflar tanımlayıp bu sınıflardan nesneler üretebilirsiniz; bu, işleri çok kolaylaştırır. - Etkileşimli: Bir komutu yazıp çalıştırdığınızda cevabını hemen alırsınız. - Birleştirilebilir (glue language): Başka dillerle birlikte kullanılabilir; ör. C/C++ için CPython, Java için Jython, .NET için IronPython [belirsiz: transkriptte "Saydın / Cahit" diye bozuk geçiyor]. - Taşınabilir: Linux, Windows ve macOS'ta çalışır.

Python ile neler yapılır? - "Veri günümüzün petrolüdür." Veriyi değerlendiren Google, Facebook gibi şirketler kısa sürede dev boyutlara ulaştı; veri bilimi diye yeni bir alan doğdu ve geleceğe damgasını vuracağını söylemek kehanet sayılmaz. Veri bilimi için en çok kullanılan dil Python'dur: Keras, TensorFlow, PyTorch gibi kütüphanelerle verilerle "top gibi oynayabilir", analizleri kolayca yapabilirsiniz. - Büyük veri için de tercih edilir; yaygın kullanılan Spark, Python ile çalışabilir. - Web geliştirme, masaüstü ve Android uygulamaları, oyunlar, blockchain, uzaktan kontrol ve görüntü işleme yapılabilir. Google, NASA gibi büyük kurumlar Python kullanır.

Hocanın tavsiyesi: Python'u bu dersle hızlıca öğrenin, ardından Python kütüphaneleriyle bol bol pratik yapın; pratik yaptıkça Python'u daha çok seversiniz.

Değişkenler, isimlendirme kuralları ve yorumlar (≈00:14–00:17)

Python'da değişken oluşturmak çok kolaydır. = atama operatörüdür: Sağdaki değeri soldaki isme atar.

x = 5
x            # 5

y = "Eğitim şart"
print(y)     # Eğitim şart

"String" kelimesi kafanızı karıştırmasın: String karakter dizisidir, metin de denebilir ve tırnak içinde gösterilir.

Büyük/küçük harf duyarlılığı: Python büyük ve küçük harfi ayırt eder. x'e 5 atadıktan sonra X yazılırsa "X tanımlı değil" hatası (NameError) alınır. Kod yazarken buna çok dikkat etmek gerekir.

İsimlendirme kuralları: - Değişken adları harf ve rakamdan oluşabilir ama rakamla başlayamaz. - İsimde boşluk bırakılmaz; alt çizgi kullanılır:

benim_adim = "Ali"
  • Her dilin kendine özgü sözdizimi vardır ve bu sözdizimi anahtar kelimeler (keywords) içerir. Anahtar kelimeler değişken adı olarak kullanılamaz. Ör. class bir anahtar kelimedir; editörde rengi farklı görünür ve değişken adı olarak kullanılırsa hata verir.

String'lerde operatörler: Genel olarak aritmetik operatörler string'lere uygulanamaz; istisnalar + ve *'dır.

"Ali" + "Veli"   # 'AliVeli'  -> + iki string'i uç uca birleştirir
"Ali" * 3        # 'AliAliAli' -> * string'i tekrar ettirir

Yorum (açıklama) satırları: # sembolü kullanılır. Editör #'den sonrasını açıklama olarak algılar, rengini değiştirir ve çalıştırmaz.

r = 35  # Ali'nin yaşı

Veri tiplerine genel bakış (≈00:17–00:24)

Bellekte veri pek çok biçimde saklanabilir: Bir kişinin yaşı sayı olarak, adresi metin olarak tutulur. Python'da 5 standart veri tipi anlatılıyor: sayısal, string, liste, demet (tuple) ve sözlük (dictionary).

Sayısal tipler

s = 1
print(s)      # 1
del s         # değişkeni siler
s             # NameError: name 's' is not defined

Python'da üç sayısal tip vardır: int (tam sayı), float (ondalıklı sayı), complex (karmaşık sayı). Bir değişkenin tipini öğrenmek için type() kullanılır.

x = 5
type(x)       # int

y = 5.0
type(y)       # float

z = 5 + 3j
type(z)       # complex

Not: Transkriptte karmaşık sayı örneği "beş artı 300i" diye bozuk geçiyor; Python'da sanal kısım j ile yazılır (ör. 5 + 3j).

String (giriş)

Karakterlerin bir araya gelmesidir, tırnak içinde yazılır. Çift ya da tek tırnak kullanılabilir.

s = "Eğitim şart"
s = 'Eğitim şart'   # aynı sonuç
print(s[0])         # 'E'  -> indeks 0'dan başlar
print(s[0:5])       # 'Eğiti' -> 0'dan 5'e kadar (5 dahil değil)
print(s[-1])        # 't'  -> son eleman için -1

Liste (giriş)

Farklı veri tiplerini bir araya getirir; elemanlar virgülle ayrılır ve köşeli parantez içinde yazılır.

liste = ["ABC", 123, 12.6]
print(liste)
type(liste)       # list
print(liste[0])   # 'ABC'
print(liste[-1])  # 12.6
print(liste[0:2]) # ['ABC', 123] -> 0 ve 1 alınır, 2. indeks alınmaz

Demet / tuple (giriş)

Listelere benzer, ama elemanları değiştirilemez: Bir kez tanımlandıktan sonra üzerinde değişiklik yapılamaz. Listeler köşeli parantezle, demetler normal parantezle yazılır.

demet = (123, "ABC", 4.56)
type(demet)      # tuple
print(demet[0])  # 123
print(demet[-1]) # 4.56
print(demet[1:2])# ('ABC',) -> yalnızca ABC

Sözlük / dictionary (giriş)

Süslü parantez içine konan anahtar–değer (key–value) çiftlerinden oluşan yapısal bir tiptir. Adından da anlaşılacağı gibi sözlüğe benzer: Terimleri anahtar, açıklamaları değer gibi düşünebilirsiniz.

yas = {"Ahmet": 18, "Selim": 20}
type(yas)            # dict
print(yas["Ahmet"])  # 18
print(yas.keys())    # yalnızca anahtarlar
print(yas.values())  # yalnızca değerler

Anahtarlar genelde sayı ya da string olur; değerler her tipten olabilir.

Tip dönüşümleri (≈00:24–00:26)

Bazen veri tiplerini birbirine dönüştürmek gerekir:

int("34")    # 34   -> string'i tam sayıya çevirir
int(3.12)    # 3    -> ondalıklı sayının yalnızca tam kısmını alır
float(5)     # 5.0  -> tam sayıyı ondalıklıya çevirir
str(15)      # '15' -> sayıyı string'e çevirir

String'ler ayrıntılı (≈00:26–00:38)

Uzunluğu bir olan string karakterdir; ama Python'da "karakter" ayrı bir veri tipi değildir. Karakterler bir araya gelerek string'i oluşturur. String'ler tek, çift veya üç tırnakla yazılabilir.

"Tirendaz Akademi"
'Tirendaz Akademi'
'Tirendaz Akademi"   # SyntaxError: hangi tırnakla başladıysanız onunla bitirmelisiniz

Kesme işareti (apostrof) sorunu

'Ali'nin kitabı'      # Hata: Python ikinci tek tırnağı string'in bitişi sanar

İki çözüm vardır:

"Ali'nin kitabı"      # 1) Dışta çift tırnak, içte tek tırnak
'Ali\'nin kitabı'     # 2) Kaçış işareti (ters eğik çizgi, backslash)

Tek ve çift tırnağın birlikte kullanılabilmesi metin yazmayı kolaylaştırır.

print ile doğrudan yazmanın farkı

x = "Tirendaz Akademi"
x             # 'Tirendaz Akademi'  -> konsol tırnaklı gösterir
print(x)      # Tirendaz Akademi    -> print tırnaksız yazar

print("Tirendaz\nAkademi")   # \n okunur, Akademi alt satıra geçer
"Tirendaz\nAkademi"          # konsolda \n olduğu gibi görünür

print string'in içini okur ve \n (yeni satır) gibi kaçış dizilerini uygular; konsolda değeri doğrudan yazdığınızda ise ifade olduğu gibi gösterilir.

Operatörler

x = "Ali"
y = "Veli"
x + y           # 'AliVeli'
x + " " + y     # 'Ali Veli' -> araya boşluk
print(x, y)     # Ali Veli   -> print virgülle verilen değerleri boşlukla yazar
3 * x           # 'AliAliAli'

Kullanıcıdan string almak, uzunluk ve indeksleme

x = input("İsim giriniz: ")   # kullanıcı "tirendaz" yazdı
print(x)
type(x)       # str
len(x)        # 8

x[0]          # 't'
x[3]          # 'e'   -> t:0, i:1, r:2, e:3
x[-1]         # 'z'
x[1:5]        # 'iren' -> 1'den 5'e kadar, 5 dahil değil
x[2:]         # 'rendaz' -> 2. indeksten sonrası
x[:6]         # 'tirend' -> 6. indekse kadar

in ve not in

"e" in x        # True
"ç" in x        # False
"g" not in x    # True
"i" not in x    # False

String metotları

Metotlarla string'lerle "top gibi oynanabilir". Tüm metotları görmek için:

dir(str)

x.upper()                 # 'TIRENDAZ'  -> bütün harfleri büyütür
x.capitalize()            # 'Tirendaz'  -> yalnızca ilk harfi büyütür
x.replace("daz", "kaç")   # 'tirenkaç'  -> bir ifadeyi başkasıyla değiştirir
x.index("e")              # 3           -> karakterin indeksini bulur

str sınıfının 40'tan fazla metodu vardır. Bilgi almak için internete bakılabilir ya da help kullanılabilir:

help()        # etkileşimli yardım; "str" yazıp Enter -> str metotlarının özeti
help(len)     # len hakkında yardım

Sayı ↔ string dönüşümleri

str(123)        # '123'
str(1.23)       # '1.23'
float("1.23")   # 1.23

Listeler ayrıntılı (≈00:37–00:47)

Liste yapısal bir veri tipidir; klasik dillerdeki dizi (array) yapısının genişletilmiş hâlidir. İçinde aynı anda sayısal, string ve mantıksal (boolean) değerler bulunabilir; hatta listenin içinde liste bulunabilir.

liste = ["gül", 10, True]
print(liste)
type(liste)      # list
liste[0]         # 'gül'
liste[-1]        # True
liste[0:2]       # ['gül', 10]
liste[1:]        # [10, True]   -> 1. indeksten itibaren
liste[:2]        # ['gül', 10]  -> 2. indekse kadar
len(liste)       # 3

İç içe liste

liste.append([1, 2, 3])   # [belirsiz: transkriptte ekleme yöntemi net değil]
len(liste)                # 4 -> [1, 2, 3] tek bir eleman sayılır
liste[3][0]               # 1 -> önce dıştaki indeks, sonra içteki indeks

Operatörler ve değiştirme

x = [1, 2, 3]
liste + x            # iki liste birleşir

10 in liste          # True
11 in liste          # False

liste[0] = "papatya" # listeler değiştirilebilir (mutable)

Liste metotları

dir(list)   # tüm liste metotları

isimler = ["Ali", "Veli", "Ayşe"]
maaslar = [2000, 3000, 4000]

isimler.append("Mert")      # sona tek eleman ekler
isimler.extend(maaslar)     # listeye başka bir listenin elemanlarını ekler
isimler.insert(0, "Bahar")  # istenen indekse eleman yerleştirir
isimler.index("Ali")        # elemanın indeksini verir

isimler.sort()              # alfabetik sıralar
maaslar.sort()              # küçükten büyüğe sıralar
isimler.reverse()           # sondan başa çevirir: ['Ayşe', 'Veli', 'Ali']

isimler.remove("Ali")       # elemanı siler; silinene artık ulaşılamaz
print(isimler.pop(1))       # indeksi verilen elemanı çıkarır AMA döndürür;
                            # çıkan eleman programda başka yerde kullanılabilir
del isimler[2]              # indeksi verilen elemanı siler
del isimler                 # listenin tamamını siler -> sonra NameError

Not: Hoca her metot öncesinde isimler listesini yeniden oluşturarak örnekleri bağımsız çalıştırıyor.

Aritmetik işlemler, gömülü fonksiyonlar ve math modülü (≈00:47–00:53)

Python bilimsel hesaplamalarda çok güçlüdür; sık kullanılan matematiksel operatörler gömülü (built-in) gelir.

7 + 2     # 9
7 - 2     # 5
7 * 2     # 14
7 / 2     # 3.5
7 // 2    # 3   -> tam sayı bölme, ondalık kısım atılır
7 % 2     # 1   -> bölümden kalan (mod)

3 + 4 * 5     # 23 -> işlem önceliği: önce çarpma
(3 + 4) * 5   # 35 -> önce parantez

Değişkenlerle işlem:

x = 5
x + 6    # 11
x * 3    # 15
x / 2    # 2.5

Sayı ile string doğrudan birleştirilemez:

print(x + " güzel sayı")        # TypeError
print(str(x) + " güzel sayı")   # 5 güzel sayı

Not: Hoca sayıyı tırnak içine alarak ("5" + " güzel sayı") gösterdi; str(x) aynı işi değişkenle yapar.

Gömülü fonksiyonlar

abs(-3)      # 3   -> mutlak değer
pow(2, 3)    # 8   -> üs alma (2'nin küpü)
max(2, 3)    # 3
min(2, 3)    # 2
round(2.3)   # 2   -> ondalık kısım 5'ten küçükse aşağı
round(2.8)   # 3   -> 5'ten büyükse yukarı yuvarlar
sqrt(9)      # NameError -> sqrt gömülü değil, math modülündedir

Not: Python 3'te round tam .5 değerlerinde "en yakın çift sayıya" yuvarlar (round(2.5) == 2).

math modülü

Tuple (demet) ayrıntılı (≈00:53–00:57)

Tuple yapısal bir veri tipidir, farklı tipleri barındırır ve listelere çok benzer. İki önemli farkı vardır: 1. Listeler köşeli, tuple'lar normal parantezle yazılır. 2. Listenin elemanları değiştirilebilir, tuple'ın elemanları değiştirilemez.

L = [1, 2, 3]
T = (1, 2, 3)

L[1] = 55   # çalışır -> [1, 55, 3]
T[1] = 44   # TypeError: 'tuple' object does not support item assignment

Tuple parantezsiz de yazılabilir ve elemanları ayrı değişkenlere açılabilir (unpacking):

koordinatlar = 2, 3, 4
x, y, z = koordinatlar
print(x, y, z)   # 2 3 4

Tuple içine liste de yazılabilir; tuple'ın içindeki liste değiştirilebilir:

x = ([1, 2, 3], [22, 33, 44])   # [belirsiz: ikinci listenin ilk elemanları transkriptte net değil]
type(x)        # tuple
len(x)         # 2
x[1][2] = 99   # hata yok
print(x)       # ([1, 2, 3], [22, 33, 99])

Hocanın benzetmesi: Tuple, içindeki listenin "dünyasına karışmaz"; listenin dünyasına girdikten sonra elemanlarla istediğiniz gibi oynayabilirsiniz.

sayi1 = int(input("Lütfen bir sayı giriniz: "))

Fonksiyonlar (≈01:00–01:05)

Fonksiyon, basitçe kodların bir araya getirilmesidir. Görevi girdi almak, işlemek ve çıktı vermektir. print de bir fonksiyondur: Parantez içindekini ekrana yazmak gibi özel bir görevi vardır. Gömülü fonksiyonların yanında kendi fonksiyonlarımızı da yazabiliriz; bunun için anahtar kelime def'tir.

def slm():
    print("Selam")
    print("herkese")

slm()   # fonksiyonu çağırmak

Kurallar: - def, ardından boşluk içermeyen fonksiyon adı, parantez ve iki nokta üst üste gelir. - Enter'a basınca girintili satıra geçilir; burası fonksiyonun gövdesidir. Girinti devam ettikçe Python fonksiyonun sürdüğünü anlar; girintiden çıkıldığında fonksiyon biter. - Fonksiyonu tanımlamak onu çalıştırmaz; önce tanımlanır, kullanılacağı zaman çağrılır.

Parametreler (argümanlar)

def slm(isim, yas):
    print("Selam " + isim + " yaşınız: " + yas)

slm("Ali", "35")   # Selam Ali yaşınız: 35

Yaş burada + ile birleştirildiği için string olarak (tırnak içinde) verildi.

return ile değer döndürmek

def kare_al(say):
    say * say

kare_al(2)          # ekrana bir şey yazılmaz
print(kare_al(2))   # None -> fonksiyon bir değer döndürmüyor

def kare_al(say):
    return say * say

print(kare_al(2))   # 4
print(kare_al(5))   # 25

Fonksiyondan geri bilgi almak için return deyimi kullanılır.

Koşul durumları: if, elif, else (≈01:05–01:11)

Birden fazla alternatif olduğunda koşul kontrol edilerek programın karar vermesi sağlanır.

puan = int(input("Puan giriniz: "))   # input string döndürür -> int'e çevir

if puan >= 50:
    print("Tebrikler geçtiniz")
else:
    print("Maalesef kaldınız")
  • Koşuldan sonra iki nokta üst üste zorunludur; yoksa hata alınır.
  • Python'da girintiler çok önemlidir. Elle girinti verilecekse 4 boşluk ya da Tab kullanılır; editör Enter'dan sonra otomatik girinti verir.
  • else'in koşulu yoktur: if koşulu sağlanmazsa doğrudan else bloğu çalışır. else olmadan 40 girildiğinde ekrana hiçbir şey yazılmaz, çünkü programa ne yapacağı söylenmemiştir.

elif ile birden çok koşul

sayi = int(input("Bir sayı giriniz: "))

if sayi < 100:
    print("Girdiğiniz sayı 100'den küçüktür")
elif sayi > 500:
    print("Girdiğiniz sayı 500'den büyüktür")
else:
    print("Girdiğiniz sayı 100 ile 500 arasındadır")

Çalışma mantığı: Önce if koşuluna bakılır; sağlanırsa o blok çalışır. Sağlanmazsa elif'e geçilir; o da sağlanmazsa else çalışır. 85 → ilk blok; 600 → elif bloğu; 300 → else bloğu.

Mantıksal değerler ve mantıksal operatörler (≈01:11–01:15)

Bilgisayar bilimi 1 ve 0 üzerine kuruludur: 1 doğru (True), 0 yanlış (False) demektir. True/False değeri alan ifadelere mantıksal (boolean) ifadeler denir.

x = 5
x == 5   # True  -> eşitlik kontrolü için ==
x == 6   # False

Python'da nesnelerin mantıksal bir değeri vardır: Genel olarak sıfır ve boş veri yapıları False, geri kalan her şey True'dur. Bunu bool() gösterir:

bool(10)    # True
bool("ne")  # True   [belirsiz: örnek metin]
bool(0)     # False
bool("0")   # True  -> tırnak içindeki 0 bir string'dir, boş değildir [belirsiz: örnek değer]
bool([])    # False -> boş liste

and, or, not

python = True
java = True

if java and python:
    print("Doğru")
else:
    print("Yanlış")
  • and (ve): İki ifade de doğruysa sonuç doğrudur; biri bile yanlışsa sonuç yanlıştır.
  • or (veya): İfadelerden biri doğruysa sonuç doğrudur; ikisi de yanlışsa sonuç yanlıştır.
  • not (değil): Mantıksal değeri tersine çevirir: True → False, False → True.
python = True
not python   # False
python = False
not python   # True

Karşılaştırma operatörleri ve iki uygulama (≈01:15–01:20)

def en_buyuk(say1, say2, say3):

        return say2
    else:
        return say3

while döngüsü ve kelime tahmin oyunu (≈01:25–01:34)

Bazen kodların defalarca tekrar etmesi gerekir. Aynı satırı kopyala-yapıştırla beş kez yazmak zaman kaybıdır; döngülerle bu iş kolayca yapılır.

while döngüsünde belirli bir koşul sağlandığı sürece kod bloğu tekrar eder. Hocanın üç altın kuralı: (1) başlangıç değeri, (2) koşul, (3) adım değeri. Bu üçü doğru yazılırsa döngü hatasız çalışır; adım değeri yazılmazsa döngü sonsuza kadar sürer.

i = 1                          # 1) başlangıç değeri
while i <= 5:                  # 2) koşul
    print("Tirendaz Akademi")
    i += 1                     # 3) adım değeri (i = i + 1'in kısa yazımı)

Nasıl çalışır? i = 1 → 1 ≤ 5 sağlanır, metin yazılır, i 2 olur, döngünün başına dönülür. Bu böyle sürer; i 6 olduğunda koşul sağlanmaz ve döngüden çıkılır.

Uygulama: Basit kelime tahmin oyunu

gizli_kelime = "tirendaz"
tahmin = ""

while tahmin != gizli_kelime:
    tahmin = input("Tahmin giriniz: ")

print("Tebrikler kazandınız")

Tahmin yanlış olduğu sürece kullanıcıdan yeni tahmin istenir.

Geliştirilmiş sürüm: Tahmin hakkı 3

gizli_kelime = "tirendaz"
tahmin = ""
tahmin_sayisi = 0
tahmin_limit = 3
tahmin_cikis = False

while tahmin != gizli_kelime and not(tahmin_cikis):
    if tahmin_sayisi < tahmin_limit:
        tahmin = input("Tahmin giriniz: ")
        tahmin_sayisi += 1
    else:
        tahmin_cikis = True

if tahmin_cikis:
    print("Üzgünüz kaybettiniz")
else:
    print("Tebrikler kazandınız")

Özet: Döngü iki koşulla döner: Tahmin gizli kelimeye eşit değilse ve tahmin_cikis False ise. Doğru tahminde döngü biter, tahmin_cikis False kaldığı için oyun kazanılır. Üç hakta bilinemezse tahmin_cikis True olur, döngü koşulu sağlanmaz ve oyun kaybedilir.

break, continue, pass (≈01:39–01:44)

break

Döngüden çıkmak için kullanılır. Hocanın ifadesiyle break "işi gücü bırak, döngü dışına çık" der.

sayac = 0

    if sayac == 5:

continue

Kendisinden sonraki işleri durdurur ve sonraki adım için döngünün başına döner: "İşi gücü bırak, döngü başına dön."

for sayilar in range(20):

Kümeler (set) ve frozenset (≈01:44–01:53)

Python'daki küme kavramı matematikteki gibidir: Her eleman bir kez yazılır ve elemanların sırasının önemi yoktur. Süslü parantezle oluşturulur.

kume = {1, 2, 3}
type(kume)    # set

s = "Ankara"
a = set(s)    # string'i kümeye çevirir; tekrar eden 'a'lardan yalnız biri alınır

liste = [1, 2, 3, 1, 2, 4]
b = set(liste)   # {1, 2, 3, 4} -> tekrar edenler bir kez alınır

Küme işlemleri (operatörlerle)

A = {1, 2, 3, 4, 5}
B = {4, 5, 6, 7, 8, 9}

print(A | B)   # birleşim
print(A & B)   # kesişim: {4, 5}
print(A - B)   # fark (A'da olup B'de olmayan): {1, 2, 3}
print(A ^ B)   # simetrik fark: {1, 2, 3, 6, 7, 8, 9}

Küme metotları

dir(set)

A = {1, 2, 3, 4}
A.add(100)          # eleman ekler
yedek = A.copy()    # kopyalar
A.discard(1)        # eleman siler
A.remove(2)         # eleman siler

A = {1, 2, 3, 4}
B = {3, 4, 5, 6}
A.union(B)                  # {1, 2, 3, 4, 5, 6}
A.intersection(B)           # {3, 4}
A.difference(B)             # {1, 2}
A.symmetric_difference(B)   # {1, 2, 5, 6}
A.issubset(B)               # False; A = {3, 4} yapılırsa True
B.issuperset(A)             # True -> B, A'yı kapsar
3 in A                      # True
1 in A                      # False (A = {3, 4} iken)

Not: Kümeler sırasız olduğu için ekrana basılan sıra garanti değildir. Not: discard olmayan bir elemanı sessizce geçer; remove ise KeyError verir. Derste bu fark anlatılmadı.

Hata yönetimi: try, except, finally (≈01:53–02:01)

Program yazarken hatalarla karşılaşılabilir. Ör. sayı beklenen yerde kullanıcı sayı dışında bir şey girerse Python programı durdurur ve hata verir; program "çöker". Olası hataları önceden kestirip önlem almak gerekir; bunun için try/except kullanılır.

sayi = int(input("Bir sayı giriniz: "))
kare = sayi ** 2
print(kare)
# 5 -> 25 ;  harf girilirse -> ValueError: invalid literal for int() with base 10

try:
    sayi = int(input("Bir sayı giriniz: "))
    kare = sayi ** 2
    print(kare)
except:
    print("Geçersiz giriş")

Ama böyle yazınca bütün hatalar için aynı mesaj verilir ve kullanıcı nerede hata yaptığını anlamaz. Python'da birçok hata türü vardır; except'te hata türü belirtmek daha iyidir:

except ValueError:
    print("Geçersiz giriş")

Birden fazla hata türü

İki sayının bölümünde iki hata olabilir: Sayı dışı giriş (ValueError) ve sıfıra bölme (ZeroDivisionError; bir sayının sıfıra bölümü tanımsızdır).

try:
    sayi1 = int(input("Bir sayı giriniz: "))
    sayi2 = int(input("Bir sayı daha giriniz: "))
    print(sayi1 / sayi2)
except ValueError:
    print("Geçersiz giriş")
except ZeroDivisionError:
    print("Sayı sıfıra bölünemez")

Hata türleri tek parantezde de yazılabilir; as ile Python'un kendi hata mesajı da gösterilir:

except (ValueError, ZeroDivisionError) as hata:
    print("Geçersiz giriş", hata)

finally

Hata olsa da olmasa da finally bloğundaki kodlar mutlaka çalışır. Özellikle dosya işlemlerinde kullanılır: Dosya açıldıktan sonra kapatılması önemlidir; ama arada hata olursa kapatma komutuna hiç ulaşılamayabilir.

try:
    dosya = open("tirendazakademi.txt", "r")
except IOError:
    print("Bir hata oluştu")
finally:
    dosya.close()

Not: Bu örnekte dosya hiç açılamazsa dosya değişkeni tanımlanmamış olur ve finally içindeki close() bu kez NameError verir. Hocanın da sonraki bölümde önerdiği with kullanımı bu sorunu ortadan kaldırır.

Dosya okuma (≈02:01–02:07)

Spyder'da View → Panes → Files [belirsiz: menü adı] ile çalışma dizinindeki dosyalar görülür. Çalışma dizini, çalışmaların kaydedildiği yerdir; yeri sağ üst köşede görünür ve oradan değiştirilebilir. Dizinde öğrencilerin matematik notlarının bulunduğu notlar.txt dosyası var.

Dosya okumak/yazmak için open kullanılır; iki parametre alır: dosya adı ve açılma modu.

Mod Anlamı
"r" Okuma; yalnızca okunur, değişiklik yapılamaz (varsayılan)
"w" Yazma; değişiklik ve yeni bilgi eklenebilir, ama var olan içeriğin üzerine yazar
"a" Ekleme (append); var olan değiştirilmez, yalnızca sona eklenir
"r+" Hem okuma hem yazma 
dosya = open("notlar.txt", "r")
dosya = open("notlar.txt")    # ikinci parametre boşsa okuma modunda açılır

Dosya tam yoluyla da açılabilir: Dosya gezgininde yol kopyalanıp yapıştırılır; Windows yolundaki ters eğik çizgiler (\) değiştirilmelidir, çünkü Python onları kaçış işareti olarak algılar. Sonra yolun sonuna dosya adı eklenir.

Not: Hocanın düz eğik çizgi kullandığı anlaşılıyor ("C:/Users/.../notlar.txt"); r"C:\...\notlar.txt" ya da \\ de çalışır.

Açık kalan dosyalar sistemi gereksiz yere meşgul eder; iş bitince kapatılmalıdır:

dosya.close()   # kapandıktan sonra dosyaya ulaşılamaz

Okuma metotları

dosya = open("notlar.txt", "r")
print(dosya.readable())    # True -> dosya okunabilir modda
print(dosya.read())        # tüm içerik

print(dosya.readline())    # birinci satır
print(dosya.readline())    # tekrar çağrılınca ikinci satır

print(dosya.readlines())   # bütün satırlar bir LİSTE olarak
print(dosya.readlines()[1])# liste olduğu için indeksle tek satır alınır

for notlar in dosya:       # for ile satır satır okuma
    print(notlar)

Not: Hoca bu satırları ayrı ayrı çalıştırıyor. Hepsi aynı açık dosya üzerinde peş peşe çalışırsa, okuma imleci ilerlediği için sonrakiler boş döner.

with bloğu

Hata olduğunda kapatma satırına gelinmeden akış kesilebilir ve dosya açık kalır. Önceki bölümdeki try/finally bir çözümdü; ancak dosyanın otomatik kapanması için with kullanmak daha iyidir, close() yazmaya gerek kalmaz.

with open("notlar.txt", "r") as dosya:
    print(dosya.read())
# blok bitince dosya otomatik kapanır

Dosyaya yazma: sona, başa ve ortaya ekleme (≈02:07–02:12)

Sona ekleme ("a")

with open("notlar.txt", "a") as dosya:
    dosya.write("Burak 100")

Ekrana bir şey yazılmaz, ama dosyada son satırdaki "Deniz 80"in hemen yanına "Burak 100" eklenir. Yeni satıra eklemek için başa kaçış karakteri konur:

with open("notlar.txt", "a") as dosya:
    dosya.write("\nBurak 100")

Yazma modu ("w")

Yazma modunda yazılan bilgi dosyadaki bilgilerin üzerine yazılır; dikkatli kullanılmazsa eski bilgiler silinir. Bu modla yeni dosya da oluşturulabilir:

with open("notlar1.txt", "w") as dosya:
    dosya.write("Burak 100")   # notlar1.txt oluşur
# "Fatih 100" yazılıp tekrar çalıştırılırsa "Burak 100" gider, "Fatih 100" gelir

Başa ekleme ("r+" + seek)

with open("notlar.txt", "r+") as dosya:
    x = dosya.read()          # önce mevcut içeriği oku ve sakla
    dosya.seek(0)             # imleci 0. konuma (dosyanın başına) getir
    dosya.write("Fatih 100\n" + x)

seek dosya üzerinde gezinmeyi sağlar; seek(0) imleci sıfırıncı bayta getirir.

Ortaya ekleme (readlines + insert + writelines)

readlines liste döndürdüğü için listelerin değiştirilebilir olmasından yararlanılır:

with open("notlar.txt", "r+") as dosya:
    veri = dosya.readlines()
    veri.insert(1, "Ali 70\n")   # 1. indekse ekle (orada "Ahmet 85" vardı)
    dosya.seek(0)
    dosya.writelines(veri)

Sonuçta 1. indeksteki satırın yerine "Ali 70" eklenir, diğer satırlar aşağı kayar.

Not: Türkçe karakterli dosyalarda open(..., encoding="utf-8") vermek, özellikle Windows'ta karakter bozulmasını önler. Derste anlatılmadı.

Modüller ve paket yönetimi (≈02:13–02:19)

Modüller aslında Python dosyalarıdır: Birbiriyle ilgili kodlar bir araya getirilip bir dosya oluşturulur; bu dosyaya modül denir. Modüllerde hazır fonksiyonlar vardır; bunları yeniden yazmaya gerek yoktur. İki tür modül vardır: hazır modüller ve kendi yazdığımız modüller.

Hazır modüller

import math          # Spyder altını sarı çizer: "import ettin ama kullanmadın" uyarısı;
                     # modülden bir fonksiyon kullanılınca uyarı kaybolur
dir(math)            # modüldeki tüm fonksiyonlar
math.sqrt(16)        # 4.0
math.factorial(5)    # 120

import math as m     # uzun adı kısaltma
m.factorial(6)       # 720

from math import sqrt, factorial   # yalnızca gerekenleri al
sqrt(36)             # 6.0
factorial(4)         # 24

from math import *   # hepsini al -> TAVSİYE EDİLMEZ

Hocanın ifadesiyle "Amerika'yı yeniden keşfetmeye gerek yok"; hazır fonksiyonları kullanın. from math import * tavsiye edilmez, çünkü bütün fonksiyonlar kontrolsüzce içe aktarılır; kendi yazdığınız fonksiyonların adlarıyla çakışabilir ve program düzgün çalışmayabilir.

Üçüncü taraf modüller: pip ve conda

math gibi standart modüllerin yanında, gömülü gelmeyen üçüncü taraf (third-party) modüller internetten indirilerek kullanılır. Bunun için pip kullanılır; Python'u bir platformla kurduğunuzda pip genellikle yüklü gelir (çok nadiren gelmezse ayrıca indirilir). pip ile paket yüklenir, güncellenir ve kaldırılır:

pip install modul_adi

Python'u Anaconda ile kullanıyorsanız conda paket yöneticisini de kullanabilirsiniz.

Kendi modülümüzü yazmak

Kendi fonksiyonlarınızı yazdığınız her dosya aslında bir modüldür ve başka bir dosyada kullanılabilir. Dikkat: Kullanılacak modül aynı çalışma dizininde olmalıdır. Özellikle çok kişinin çalıştığı büyük projelerde modüllerle çalışmak, kodların bir merkezden yönetilmesini sağlar.

Çalışma dizininde sağ tık → New → File ile toplama.py oluşturulur:

# toplama.py
def top(a, b):
    print(a + b)

# başka bir dosyada
import toplama as tp
tp.top(3, 4)   # 7

Nesne tabanlı programlama: sınıf, nesne, __init__ (≈02:19–02:27)

Python nesne tabanlı bir dildir; Python'da her şey bir nesnedir, fonksiyonlar ve veri tipleri de. Ama günlük hayattaki her şeyi string ya da int gibi tiplerle ifade edemeyiz; kendi nesnelerimizi oluşturmak için sınıf (class) kullanılır. Sınıflar nesne üretmemizi sağlayan soyut veri tipleridir; nesneler sınıfların somutlaşmış örnekleridir (instance).

Hocanın benzetmesi: Bilgisayar bir sınıftır; RAM, işlemci, anakart, klavye, ekran onun nitelikleridir. Laptop bilgisayar sınıfının bir örneğidir: Bilgisayar sınıfının bütün özelliklerini taşır, ayrıca kendine özgü özellikleri vardır.

class Ogrenciler:
    pass          # şimdilik boş sınıf
  • Sınıf class anahtar kelimesiyle oluşturulur; ardından gelen kelime sınıfın adıdır. Sınıf adlarında büyük harfle başlamak adettendir.
  • Sınıfın değişkenleri (nitelikleri) ve metotları sınıfın gövdesine yazılır.

Sınıf nitelikleri

class Ogrenciler:
    isim = ""        # değer atanmadı [belirsiz: boş string mi, başka bir şey mi]
    okul = "lise"
    yas = 18

print(Ogrenciler.isim)   # boş
print(Ogrenciler.okul)   # lise
print(Ogrenciler.yas)    # 18

Ogrenciler.yas = 17      # başlangıç değeri değiştirilebilir
print(Ogrenciler.yas)    # 17

Niteliklere erişmek için sınıf adı parantezsiz kullanılır ve nokta konur.

Nesne üretmek

Nesne üretmek fonksiyon çağırmaya benzer: Sınıf parantezle çağrılıp bir değişkene atanır. Nesne, sınıfın bütün özelliklerini taşır.

talebe1 = Ogrenciler()
print(talebe1.okul)     # lise

talebe1.isim = "Ali"    # boş niteliğe atama
print(talebe1.isim)     # Ali
print(talebe1.okul)     # lise -> atanmayan nitelik sınıftaki başlangıç değerini alır

talebe2 = Ogrenciler()  # istediğimiz kadar nesne üretebiliriz
talebe2.isim = "Can"
print(talebe2.isim, talebe2.okul)   # Can lise

__init__ ile nesne nitelikleri

Nesnenin niteliklerini belirlemek için __init__ fonksiyonu kullanılır.

class Ogrenciler:
    def __init__(self, isim, yas):
        self.isim = isim
        self.yas = yas

talebe1 = Ogrenciler("Ali", 18)
print(talebe1.isim)   # Ali
print(talebe1.yas)    # 18
  • __init__'in ilk parametresi her zaman self olmak zorundadır; self sınıftan üretilen örnekleri (nesneleri) temsil eder.
  • self.isim = isim: Nesne oluştururken verilen ilk parametre, nesnenin isim niteliği olur.

Başka metotlar

__init__ kullanmak zorunlu değildir; başka metotlar da eklenebilir:

class Ogrenciler:
    def __init__(self, isim, yas):
        self.isim = isim
        self.yas = yas

    def goster(self):
        return "Öğrenci ismi: " + self.isim

o1 = Ogrenciler("Ali", 18)
print(o1.goster())   # Öğrenci ismi: Ali

Sınıfı başka bir modülden kullanmak

Sınıf deneme.py dosyasına yazılmışsa başka bir dosyadan import edilerek kullanılabilir:

import deneme
o2 = deneme.Ogrenciler("Ayşe", 16)   # önce modül adı, sonra sınıf adı
print(o2.isim, o2.yas)               # Ayşe 16

Kalıtım (inheritance), metot ezme ve super() (≈02:27–02:34)

Kalıtım (bazı kaynaklarda "miras alma"), nesne tabanlı programlamanın önemli özelliklerinden biridir: Bir sınıftaki özelliklerin alt sınıflara geçmesi, yani ebeveyn sınıfın (parent class) niteliklerinin çocuk sınıfa (child class) aktarılmasıdır. Hocanın benzetmesi: Gerçek hayatta da anne-babanın bazı özellikleri çocuğa geçer; çocuğun bunların yanında kendine has özellikleri de vardır.

class Ebeveyn:
    def __init__(self, isim, memleket):
        self.isim = isim
        self.memleket = memleket

    def goster(self):
        print("Adım", self.isim, "ve memleketim", self.memleket)

class Cocuk(Ebeveyn):   # parantez içine ebeveyn sınıfı yazılır
    pass

c1 = Cocuk("Ali", "İzmir")
c1.goster()   # Adım Ali ve memleketim İzmir

Ebeveynin kodları kopyala-yapıştırla çocuğa da yazılabilirdi, ama kod tekrarlanmış olurdu. Miras alma, bir kez yazılan kodun farklı yerlerde kullanılmasını sağlar ve kodu tekrardan kurtarır. Ebeveyn sınıfa üst sınıf ya da taban sınıf (base class), çocuk sınıfa alt sınıf (subclass) denir.

Yeni özellik ekleme ve metot ezme (overriding)

class Cocuk(Ebeveyn):
    okul = "lise"

    def goster(self):
        print("Okulum", self.okul)

c1 = Cocuk("Ali", "İzmir")
print(c1.okul)   # lise
c1.goster()      # Okulum lise -> çocuktaki metot çalıştı

goster hem ebeveynde hem çocukta var; çalışan, çocuk sınıftaki metottur. Alt sınıftaki tanım, üst sınıftan geleni ezer. İngilizcede buna overriding denir; Türkçede "üzerine yazma" ya da "baskın olma" diye çevrilir.

super() ile üst sınıfın kodunu kullanmak

Çocuk sınıfa kendi __init__'i yazılabilir. Üst sınıftaki fonksiyonun kodları da kullanılmak isteniyorsa super() kullanılır; super, üst sınıftaki fonksiyonları çağırmaya yarar.

class Cocuk(Ebeveyn):
    def __init__(self, isim, memleket, yas):
        super().__init__(isim, memleket)   # burada self yazılmaz
        self.yas = yas                      # üst sınıfta olmayan nitelik

    def goster(self):
        super().goster()          # üst sınıftaki goster'i çalıştır
        print("Yaşım", self.yas)  # üstüne ekstra görev

c1 = Cocuk("Ali", "İzmir", 18)
print(c1.yas)    # 18
print(c1.isim)   # Ali
c1.goster()
# Adım Ali ve memleketim İzmir
# Yaşım 18

super() yalnızca __init__ için değil, diğer metotlar için de kullanılabilir.

Özet: Kodları tekrar yazmamak için ebeveyn sınıftan çocuk sınıfa miras geçirilir. Ebeveynin nitelikleri ve metotları aynen korunur; çocuk sınıf hem ebeveynin özelliklerini taşır hem kendi özelliklerine sahip olur.

Kapsam (scope): yerel ve global değişkenler (≈02:34–02:37)

Python'da fonksiyonların ve sınıfların bir kapsama alanı vardır; buna ad uzayı (namespace) denir. Her nesnenin geçerli ve etkin olduğu bir ad uzayı vardır.

def kare():
    x = 5
    return x ** 2

print(x)   # NameError: name 'x' is not defined

Buradaki x yerel (local) değişkendir; yalnızca kare fonksiyonunun içinden erişilir. Fonksiyonun dışında tanımlanan değişken ise global olur:

x = 7

def kare():
    x = 5
    return x ** 2

print(x)        # 7  -> global x
print(kare())   # 25 -> fonksiyon önce kendi yerel x'ini kullanır

Adları aynı olsa da iki x farklı nesnelerdir. Fonksiyonlar önce kendi yerel değişkenlerini kullanır; yerel değişken yoksa global olanı kullanır:

x = 7

def kare():
    return x ** 2

print(kare())   # 49 -> yerel x olmadığı için global x kullanıldı

global anahtar kelimesi

Yerel bir değişkeni global yapmak için global kullanılır; böylece değişkene fonksiyon dışından da erişilir.

x = 10

def fonk1():
    x = 15

def fonk2():
    print(x)

fonk1()
fonk2()   # 10

def fonk1():
    global x
    x = 15

fonk1()
fonk2()   # 15

Lambda fonksiyonları ve map (≈02:37–02:40)

Normalde fonksiyon def ve bir isimle tanımlanır:

def fonk1(x):
    return x ** 2

print(fonk1(5))   # 25

def ve isim kullanmadan, lambda anahtar kelimesiyle oluşturulan fonksiyonlara lambda fonksiyonları denir. Önce lambda, sonra parametreler, iki nokta üst üste ve fonksiyonun görevi yazılır.

fonk2 = lambda x: x ** 2
print(fonk2(6))      # 36

fonk3 = lambda x, y: x + y
print(fonk3(3, 4))   # 7

Lambda fonksiyonları kısa ve isimsiz bir fonksiyon gerektiğinde kullanılır. Birden fazla parametre alabilir, ama yalnızca tek bir görev (ifade) yapar.

map ile lambda

Fonksiyonlar başka fonksiyonların içinde de kullanılabilir. map, parametre olarak bir fonksiyon ve bir liste alır; fonksiyonu listedeki her elemana uygular.

sayilar = [1, 2, 3, 4, 5]
kareler = list(map(lambda x: x ** 2, sayilar))
print(kareler)   # [1, 4, 9, 16, 25]

map sonucu doğrudan liste olarak vermez; sonuç list() içine alınarak listeye çevrilir.
