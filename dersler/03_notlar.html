03 · Çalışma Ortamı Kurulumu

Bu derste ne var: LangChain ile kod yazmaya başlamadan önce proje klasörü, VS Code, Anaconda/conda ile izole bir sanal ortam, requirements.txt ile sürümü sabitlenmiş kütüphane kurulumu ve OpenAI API anahtarının .env + python-dotenv ile güvenli şekilde yüklenmesi adım adım kuruluyor. Ders kayıtlı ve kısa (~13 dk); kod dosyası yok, komutlar anlatımdan çıkarıldı.

Not: Videodaki sürümler (langchain 0.1.6 vb.) eski LangChain 0.1.x dönemine aittir. Bugün kurulum yaparken PyPI'daki güncel sürümleri kullanın; bootcamp'in kendi requirements.txt dosyası varsa onu esas alın.

Ana kavramlar

  • Sanal ortam (virtual environment) — Projeye özel, izole bir Python + kütüphane alanı. Neden önemli: Farklı projelerin farklı sürümler istemesinden doğan çakışmaları önler; hoca her proje için ayrı ortamı "şiddetle" tavsiye ediyor.
  • Anaconda / conda — Veri bilimi odaklı platform ve onun paket/ortam yöneticisi. Neden önemli: conda create / activate / deactivate ile ortam yönetimi tek komuttur.
  • pip — Python'un paket yöneticisi; Anaconda ile birlikte gelir. Neden önemli: pip install -r requirements.txt ile tüm bağımlılıklar tek seferde kurulur.
  • requirements.txt — Kullanılan kütüphaneler ve sürümlerinin paket==sürüm listesi. Neden önemli: Ortamın başka bir makinede birebir yeniden kurulabilmesini (tekrarlanabilirlik, reproducibility) sağlar.
  • PyPI (pypi.org) — Python paketlerinin resmi deposu. Neden önemli: Paketlerin son sürümü ve yayın tarihi buradan kontrol edilir.
  • langchain / langchain-core / langchain-openai / langchain-community — LangChain'in ana paketi, çekirdek soyutlamalar, OpenAI entegrasyonu ve topluluk entegrasyonları. Neden önemli: LangChain modüler paketlere bölünmüştür; sağlayıcı entegrasyonu (OpenAI) ayrı bir paket olarak kurulur. langchain kurulunca langchain-community otomatik geldi.
  • Ortam değişkeni (environment variable) ve .env — Gizli bilgilerin (API anahtarı) koda yazılmadan, işletim sistemi değişkeni olarak taşınması. Neden önemli: Anahtar kodda görünmez, repoya sızmaz.
  • python-dotenv / load_dotenv() — .env dosyasını okuyup içindeki değişkenleri ortama yükler. Neden önemli: En pratik ve hocanın tercih ettiği yöntem.
  • .gitignore — Git'in takip etmeyeceği dosyaların listesi. Neden önemli: .env buraya yazılarak API anahtarının GitHub'a gitmesi engellenir.
  • Interpreter / Kernel seçimi — VS Code'un hangi Python'u kullanacağı (scriptler için interpreter, notebook için kernel). Neden önemli: Yanlış seçilirse kurduğunuz kütüphaneler "bulunamadı" hatası verir.

Akış / mimari

Proje klasörü (mkdir, cd)
   → VS Code (code .)
   → Sanal ortam (conda create -n langchain → conda activate langchain)
   → requirements.txt (sürümler PyPI'dan)
   → pip install -r requirements.txt
   → VS Code: Select Interpreter = langchain ortamı
   → .env (OPENAI_API_KEY=...)  +  .gitignore (.env)
   → langchain.ipynb  → Select Kernel = langchain ortamı
   → load_dotenv()  → True  → os.getenv("OPENAI_API_KEY") ile kontrol

Anahtarın yolu:

OpenAI platform → API keys → Create secret key
   → .env dosyası → load_dotenv() → ortam değişkeni OPENAI_API_KEY
   → langchain-openai / openai bu değişkeni otomatik okur

Kod / uygulama

1) Terminal komutları

mkdir langchain-for-genai
cd langchain-for-genai
code .
conda create -n langchain
conda activate langchain
pip install -r requirements.txt
pip list
  • mkdir … — proje klasörünü oluşturur.
  • cd … — klasörün içine girer; sonraki tüm dosyalar burada oluşur.
  • code . — VS Code'u bu dizinde açar (. = mevcut dizin).
  • conda create -n langchain — -n ile isim verilen yeni bir conda ortamı oluşturur (Anaconda'nın envs klasörüne).
  • conda activate langchain — ortamı etkinleştirir; bundan sonraki pip install bu ortama kurar. Her yeni terminalde tekrar gerekir.
  • pip install -r requirements.txt — -r ile dosyadaki tüm paketleri (bağımlılıklarıyla) kurar.
  • pip list — kurulu paketleri ve sürümlerini listeler (doğrulama).

2) requirements.txt

langchain==0.1.6
langchain-core==0.1.2
langchain-openai==0.0.1
python-dotenv==1.0.1
  • == — sürümü tam sabitler; ortam her yerde aynı kurulur.
  • langchain-openai — OpenAI modellerini LangChain'de kullanmak için ayrı entegrasyon paketi.
  • python-dotenv — .env okumak için. Paket adı python-dotenv, import adı dotenv (farklı olduğuna dikkat).

3) .env ve .gitignore

# .env
OPENAI_API_KEY=sk-...

# .gitignore
.env
  • .env — anahtar burada durur, kodda değil. Değişken adı OPENAI_API_KEY olmalı ki OpenAI kütüphanesi otomatik tanısın.
  • .gitignore — .env'in repoya gitmesini engeller.

4) Notebook'ta anahtarı yükleme

from dotenv import load_dotenv
load_dotenv()
  • from dotenv import load_dotenv — fonksiyonu içe aktarır.
  • load_dotenv() — çalışma dizinindeki .env'i okur, değişkenleri os.environ'a ekler; başarılıysa True döner.
import os
os.getenv("OPENAI_API_KEY")
  • os.getenv(...) — değişkenin yüklendiğini kontrol eder (gösterim amaçlı; anahtarı ekranda bırakmayın).

5) Alternatif: elle ayarlama

import os
os.environ["OPENAI_API_KEY"] = "sk-..."
  • Anahtarı doğrudan oturuma yazar. Hızlı ama anahtar kodun içinde kalır; hoca birinci yöntemi (dotenv) tavsiye ediyor.

Hocanın vurguları & pratik kurallar

  • Her proje için ayrı sanal ortam kullanın.
  • Projede çalışırken her seferinde ortamı etkinleştirin (satır başındaki ortam adına bakın).
  • Kütüphaneleri sürümleriyle requirements.txt'e yazın; son sürümleri PyPI'dan kontrol edin.
  • VS Code'da interpreter (scriptler) ve kernel (notebook) olarak oluşturduğunuz ortamı seçmeyi unutmayın.
  • API anahtarını kimseyle paylaşmayın; .env'de tutun, .env'i .gitignore'a ekleyin.
  • OpenAI anahtarı yalnızca bir kez gösterilir; kaydedin. İhtiyaç kalmayınca silin (hoca videodan sonra sildi).
  • Tercih edilen yöntem: python-dotenv + .env; os.environ ile elle atama alternatiftir.

Sık hatalar / karşılaşılan sorunlar

  • Notebook ilk çalıştırmada paket istiyor → VS Code ipykernel kurulmasını istedi; Install denince çözüldü (derste yaşandı).
  • "ModuleNotFoundError: No module named 'langchain'" → (Not: derste yaşanmadı, olası durum.) Genellikle yanlış interpreter/kernel seçili ya da paketler ortam etkinleştirilmeden kurulmuştur. Ortamı etkinleştirip tekrar kurun ve doğru kernel'i seçin.
  • load_dotenv() False dönüyor → (Not: olası durum.) .env dosyası notebook'un çalıştığı dizinde değil ya da adı yanlış (.env.txt vb.).
  • Anahtar repoya sızdı → .gitignore'a .env eklenmemiş ya da os.getenv çıktısı notebook'ta kalmış. Anahtarı OpenAI panelinden hemen silip yenisini oluşturun.
