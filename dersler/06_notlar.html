06 · Uygulama

Bu derste ne var: Önceki dersin ChatPromptTemplate + pipe (|) örneği ve "bağlam mühendisliği" vurgusu kısaca tekrarlandı. Ardından uv ile sıfırdan bir proje ortamı kuruldu ve Streamlit + OpenAI Responses API kullanılarak tek dosyalık ilk yapay zekâ uygulaması (my-first-app.py) yazılıp çalıştırıldı. Son kısımda öğrencilerin kurulum hataları çözüldü ve Streamlit uygulamasının ücretsiz yayınlanması (deploy) anlatıldı.

Ana kavramlar

  • Sanal ortam (virtual environment) — Projeye özel, izole Python + kütüphane kurulumu. Neden önemli: Projeler arasında kütüphane/versiyon çakışmasını (version conflict) önler; hoca her proje için ayrı ortam öneriyor.
  • uv — Python proje ve paket yöneticisi (uv init, uv add, uv run). Neden önemli: Hocanın tercihi; conda'ya göre hafif, yapay zekâ projelerinde standartlaşıyor.
  • pyproject.toml — Projenin bağımlılıklarını ve versiyonlarını tutan dosya. Neden: uv add ile eklenen her kütüphane buraya yazılır; proje başka makinede aynı şekilde kurulabilir.
  • .gitignore — Git'e/GitHub'a gönderilmeyecek dosyaların listesi. Neden: .env gibi API anahtarı içeren dosyaların yanlışlıkla paylaşılmasını engeller.
  • .env + python-dotenv — Gizli anahtarların dosyada tutulup load_dotenv() ile ortama yüklenmesi. Neden: Anahtar kodun içine yazılmaz; projelerde yaygın yöntem.
  • override=True — .env değerinin mevcut ortam değişkeninin üzerine yazılması. Neden: Terminalde başka bir anahtar tanımlıysa "Incorrect API key" hatasını önler.
  • Import → örnek (instance) al — Önce sınıfı import et, sonra ondan nesne oluştur (client = OpenAI()). Neden: Sadece kullanılanı import etmek belleği gereksiz doldurmaz.
  • Streamlit — Python ile hızlı web arayüzü kütüphanesi (st.title, st.text_input, st.button, st.spinner, st.write, st.warning). Neden: Yapay zekâ / ML / veri bilimi prototiplerini dakikalar içinde arayüze dökmek ve ücretsiz yayınlamak.
  • Responses API (client.responses.create) — OpenAI'ye istek atıp cevap alma. response.output_text sadece cevap metnini verir. Neden: response içinde token sayıları gibi meta veriler de var; ekrana yalnızca metin basılmak isteniyor.
  • Pipe operatörü (|) / chain — LangChain'de bir bileşenin çıktısını diğerine girdi yapar (template | model). Neden: İşlemleri zincir gibi bağlamak; "LangChain" adı buradan.
  • Bağlam mühendisliği (context engineering) — Modele doğru zamanda, doğru miktarda bilgi vermek. Neden: Az bağlam → model anlamaz; fazla bağlam → bağlam kirliliği, yüksek token maliyeti, yavaş ve karışık cevap.

Akış / mimari

Proje kurulumu:

Masaüstünde klasör aç → VS Code'da aç (File → Open Folder) → Terminal (Ctrl + `)
→ uv init --python 3.12 → uv add openai streamlit python-dotenv
→ .env (OPENAI_API_KEY=...) → my-first-app.py yaz → kaydet
→ uv run streamlit run my-first-app.py → tarayıcıda localhost

Uygulamanın çalışma akışı:

Kullanıcı soru yazar (st.text_input)
→ "Cevapla" butonu (st.button)
→ soru.strip() boş mu?
    ├─ boş   → st.warning("Önce bir soru yaz.")
    └─ dolu  → st.spinner("Cevap hazırlanıyor...")
               → client.responses.create(model, input=soru)
               → st.write(response.output_text)

Yayınlama (deploy):

Streamlit hesabı → GitHub hesabı → yeni repository (ör. my-first-app)
→ dosyaları yükle → Streamlit Community Cloud repoyu görür → public link

Önceki ders (tekrar) — LangChain zinciri:

ChatPromptTemplate (system + user; {context}, {question})
→ | model → context_chain.invoke({...}) → cevap

Kod / uygulama

1) Ortam kurulumu (terminal)

uv init --python 3.12
uv add openai streamlit python-dotenv
  • uv init → bulunduğun dizinde proje başlatır; .python-version, pyproject.toml, README.md, .gitignore dosyalarını oluşturur.
  • --python 3.12 → projenin Python sürümünü sabitler.
  • uv add ... → üç kütüphaneyi sanal ortama kurar ve pyproject.toml'a yazar. Her yeni proje klasöründe tekrar yapılmalı.

2) .env

OPENAI_API_KEY=sk-...
  • Değişken adı büyük harfle, = ile; dosya proje kök dizininde olmalı (alt klasördeyse bulunamaz).

3) my-first-app.py (ders kaynağındaki adı 1_my-first-app.py)

from dotenv import load_dotenv
from openai import OpenAI
import streamlit as st

load_dotenv(override=True)
client = OpenAI()

st.title("İlk AI Uygulamam")
soru = st.text_input("Ne sormak istersin?")

if st.button("Cevapla"):
    if soru.strip():
        with st.spinner("Cevap hazırlanıyor..."):
            response = client.responses.create(
                model = "gpt-5.6-luna",
                input = soru
            )
        st.write(response.output_text)
    else: 
        st.warning("Önce bir soru yaz.")

Satır satır: - from dotenv import load_dotenv → .env dosyasını okuyacak fonksiyon. - from openai import OpenAI → OpenAI istemci sınıfı. - import streamlit as st → her seferinde streamlit yazmamak için st kısaltması. - load_dotenv(override=True) → .env'deki anahtarı ortama yükler; override=True terminalde tanımlı eski bir anahtarın önüne geçer. - client = OpenAI() → sınıftan bir örnek; anahtarı ortamdan (OPENAI_API_KEY) kendisi okur. - st.title(...) → sayfa başlığı. - soru = st.text_input(...) → metin kutusu; içindeki metin kutunun etiketi, kullanıcının yazdığı değer soru'ya gelir. - if st.button("Cevapla"): → buton oluşturur; basıldığı anda True döner ve blok çalışır. - if soru.strip(): → baş/son boşlukları atar; geriye bir şey kalmışsa (boş değilse) devam eder. Sadece boşluk girilmesini de engeller. - with st.spinner(...) → model cevabı gelene kadar bekleme mesajı gösterir. - client.responses.create(model=..., input=soru) → modele isteği gönderir; sonuç response'ta. - st.write(response.output_text) → meta verileri değil, yalnızca cevap metnini ekrana yazar. (Girintiye dikkat: with bloğunun dışında, if soru.strip() bloğunun içinde.) - else: st.warning(...) → boş soruyla butona basılırsa uyarı.

4) Çalıştırma

uv run streamlit run my-first-app.py
  • uv run → komutu projenin sanal ortamında çalıştırır; streamlit run → dosyayı web uygulaması olarak başlatır ve localhost adresi verir.

Hocanın vurguları & pratik kurallar

  • Her proje = ayrı sanal ortam. Kütüphane/versiyon çakışmalarını önlemek için.
  • conda yerine uv'ye alışın. Anaconda kullanışlı ama büyük; uv yapay zekâ projeleri için "gerçekten harika".
  • Önce import, sonra örnek al. Sadece kullanacağını import et.
  • API anahtarı .env'de, .env .gitignore'da; GitHub'a asla gönderilmez. Anahtar kaybolursa silip yenisini al.
  • Python girintiye ve büyük/küçük harfe duyarlıdır. Girinti tutarlı olmalı (hep 4 ya da hep 2 boşluk).
  • Kodu birlikte yazın — kopyala-yapıştır yerine yazarak daha iyi öğrenilir; ilk derslerden sonra kurulum adımları hızlı geçilecek, el pratiği kazanın.
  • Bağlam: doğru zamanda doğru bilgi. Gereksiz bağlam, gereksiz tool ve MCP bağlantısı = daha fazla token, daha yavaş ve karışık cevap.
  • Prompt engineering ölmedi ama önemi azaldı; modeller kısa prompt'ları kendileri genişletiyor, bağlam mühendisliği öne çıktı.
  • Streamlit: prototip/demo için ideal, ücretsiz deploy edilebilir; tasarımda Next.js/React seviyesinde değil ama işini görür.
  • Uygulayarak öğrenin ve paylaşın. Temelden sonra chatbot, PDF yükleyip soru sorma gibi özellikler eklenecek.
  • Terminal temizleme: Windows cls, macOS/Linux clear. Terminal kısayolu: Ctrl + `.

Kendini test et

  1. Her proje için ayrı bir sanal ortam kurmak neden önerilir?
Cevap

Projeler farklı kütüphaneler ve versiyonlar kullanır; tek ortamda kütüphaneler/versiyonlar çakışabilir. Ayrı ortam izolasyon sağlar.

  1. uv init --python 3.12 hangi dosyaları oluşturur ve bunlardan hangisi .env'yi korur?
Cevap

.python-version, pyproject.toml, README.md, .gitignore (ve örnek bir Python dosyası olabilir). .gitignore, .env gibi gizli dosyaların GitHub'a gönderilmesini engeller.

  1. uv add openai streamlit python-dotenv komutundaki üç kütüphane ne işe yarar?
Cevap

openai: OpenAI modeline bağlanmak; streamlit: web arayüzü; python-dotenv: API anahtarını .env'den ortama yüklemek.

  1. load_dotenv(override=True) içindeki override=True hangi hatayı önler?
Cevap

Terminalde/sistemde zaten tanımlı farklı bir OPENAI_API_KEY varsa, .env'deki değer onun üzerine yazılır; iki anahtarın çakışmasından kaynaklanan "Incorrect API key provided" hatası önlenir.

  1. soru.strip() neden if koşulunda kullanılıyor?
Cevap

Baş ve sondaki boşlukları temizler; geriye boş metin kalırsa koşul False olur ve st.warning çalışır. Böylece boş ya da sadece boşluktan oluşan soru modele gönderilmez.

  1. st.spinner ne işe yarar, neden with bloğu içinde?
Cevap

Modelden cevap gelene kadar "Cevap hazırlanıyor..." mesajı gösterir; with bloğu bitince (istek tamamlanınca) mesaj kaybolur.

  1. Ekrana neden response değil de response.output_text yazdırılıyor?
Cevap

response nesnesi token sayıları gibi meta veriler de içerir; output_text yalnızca modelin ürettiği cevap metnidir.

  1. Streamlit uygulaması açılıyor ama sayfa boş geliyor. İlk neyi kontrol edersin?
Cevap

Dosyanın kaydedilip kaydedilmediğini (Auto Save). Derste sorunun sebebi buydu. Ardından localhost adresini başka tarayıcıda deneyebilirsin.

  1. LangChain'de template | model ifadesindeki | ne yapar?
Cevap

Pipe operatörüdür: şablonun ürettiği prompt'u modele girdi olarak aktarır ve bir zincir (chain) oluşturur; invoke ile yer tutucu değerleri verilerek çalıştırılır.

  1. "Çok bağlam = daha iyi cevap" doğru mu?
Cevap

Hayır. Gereksiz bağlam, tool ya da MCP bağlantısı token maliyetini artırır, cevabı yavaşlatır ve modelin kafasını karıştırır (bağlam kirliliği). Az bağlam da kötüdür; ilke: doğru zamanda doğru bilgi.

  1. Streamlit uygulamasını ücretsiz yayınlamak için hangi adımlar gerekir?
Cevap

Streamlit hesabı açmak, GitHub hesabına bağlanmak, GitHub'da yeni bir repository açıp dosyaları yüklemek; Streamlit (Community Cloud) repoyu görür ve public bir link ile yayınlar. İstenirse bir alan adına bağlanabilir.
